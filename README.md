# Spam-Mail-Prediction-Using-Machine-Learning
This project focuses on building an end-to-end Spam Mail Detection System using Machine Learning and Natural Language Processing (NLP) techniques.
The model classifies emails as Spam or Ham (Not Spam) based on their textual content.

# 🚀 Project Highlights

Used TF-IDF Vectorization to convert text messages into numerical features

Implemented Logistic Regression for binary classification

Performed data cleaning, preprocessing, and label encoding

Achieved ~96.7% accuracy on both training and test datasets

Built a real-time predictive system to classify new incoming emails

# 🛠️ Tech Stack

Python

Pandas, NumPy

Scikit-learn

TF-IDF Vectorizer

Logistic Regression

# 📊 Dataset

SMS Spam Collection Dataset

5,572 messages labeled as spam or ham

# 📈 Model Performance

Training Accuracy: 96.77%

Testing Accuracy: 96.68%

# ✅ Outcome

This project demonstrates practical skills in text preprocessing, feature extraction, and machine learning model-building.
making it suitable for real-world spam detection systems.
